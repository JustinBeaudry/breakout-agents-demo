# Backlog

Features the room has pitched, and which one won each round. One feature is built per round.

## How a feature gets built

1. Pitch. Anyone can call one out, in one sentence. It is written here as said. If it takes two sentences, it is two features.
2. Gate. A pitch can be voted on only if we can see it on screen and check it with a test. The presenter applies the gate and can split a pitch that is too big.
3. Vote. One hand per person per round. Most hands wins. The presenter breaks a tie toward the smaller feature.
4. Build. The winner goes through the whole loop: update `intent.md`, add its rules to `spec.md`, accept a new `plan.md`, failing test, code, review, lesson.
5. Everything that lost stays on the list for the next round.

## Pitches

Seeds are here so the first vote is never empty. Add new pitches at the bottom.
